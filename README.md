# 100 Single HTML Analysis · 百大单页逆向工程与单页工具集

一个以「单个 HTML 文件」为单位的代码研究与原创工具仓库,全部内容无需构建、浏览器直接可开。仓库分两部分:

1. **根目录:原创单页工具** —— 三个可直接使用的独立单页应用(职业规划助手、测评工具、竞赛参考页)。
2. **编号子目录:逆向分析档案 (000–007)** —— 对典型单页 HTML 的逆向工程深度解析:原始页面归档、技术机制拆解、商业化套路评估、代码质量评判,均遵循 `000 项目规范与逆向分析标准` 定义的命名与报告模板。

## 运行方式

全部为静态单页,无构建步骤、无包管理器依赖。直接双击 HTML 文件打开,或用任意静态服务器托管。依赖 AI API 或 CDN 资源的功能(职业规划助手、测评分析、Google Fonts、Three.js)需要联网。
